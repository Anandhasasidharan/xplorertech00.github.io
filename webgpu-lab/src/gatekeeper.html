Gatekeeper — every tool call meets the reference monitor

An AI agent plans a sequence of tool calls. Before each one runs, a reference monitor checks it against a deterministic capability policy: allowed, flagged, or blocked. This is the pattern from SENTRIX — a dual-LLM reference monitor that enforces capability policy before every tool call. The decisions below are computed live by the same policy and classifier rules ported from that project.
