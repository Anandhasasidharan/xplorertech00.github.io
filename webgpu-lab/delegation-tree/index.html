Delegation Tree — authority can only narrow

Delegation may narrow authority, never expand it.

A human operator hands a scope to a manager agent, the manager hands a smaller scope to a worker, and the worker hands a single-file scope to a tool. Each scope is a shell drawn inside its parent's shell, and it contracts at every hop. Try to widen a scope and the token stops at the parent boundary: the delegation is refused before any token is issued. This is the attenuation guarantee from AgentIAM — invocation-bound capability tokens where the delegation chain is the audit trail.

      Data source. The chain, SPIFFE IDs, scopes and the historical rejection are taken from AgentIAM's own demo seed (scripts/seed_demo.py). The narrowing rules and the rejection message are ported from agentiam/tokens/scope_utils.py, agentiam/tokens/attenuate.py and agentiam/dashboard/diff.py, so the checks and the wording you see are the project's real logic running in your browser. The SPIFFE IDs use the demo domain iam.local; the two button attempts are illustrative sample data built from those rules, not real token minting. No secrets or live credentials are included.

      Rendering. Three.js with vanilla JavaScript; WebGPU where the browser supports it, WebGL 2 otherwise. Drag to orbit, scroll or pinch to zoom, Space to play or pause, arrow keys to move the selection, double-click to reset the view, F for fps and backend.
